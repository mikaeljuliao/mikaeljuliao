## 🚀 Projeto em destaque

### 💰 Lumio Finance

Aplicação de gestão financeira pessoal que permite registrar despesas por texto ou áudio via WhatsApp e acompanhar as informações por meio de um dashboard web em tempo real.

O projeto foi desenvolvido como um laboratório pessoal de desenvolvimento Full Stack e está em produção, sendo utilizado por usuários ativos.

### 🧠 Arquitetura

- Front-End desenvolvido com Next.js App Router e React
- API Back-End desenvolvida com Node.js e Express
- PostgreSQL como banco de dados, com Prisma ORM
- Comunicação em tempo real com Socket.IO
- Integração com WhatsApp através do Baileys
- Google Gemini para interpretação de intenções e extração de dados
- Groq Whisper para transcrição de mensagens de áudio
- Validação e aplicação das regras de negócio realizadas pela aplicação

### 🔥 Principais funcionalidades

- Registro de gastos por texto e áudio via WhatsApp
- Autenticação vinculada ao número de WhatsApp
- Dashboard financeiro com resumo e gráficos
- Histórico de transações com edição e exclusão
- Limites mensais por categoria
- Alertas de limites via WhatsApp
- Atualização das informações em tempo real

### 🛠️ Tecnologias

**Front-end:** Next.js • React • JavaScript • Tailwind CSS • Recharts  
**Back-end:** Node.js • Express • PostgreSQL • Prisma  
**Integrações:** Google Gemini • Groq/Whisper • Baileys • Socket.IO

🔗 **Demo:** https://lumio-finance-tau.vercel.app/
